# نداء — Nida Computer Use (إضافة تحكم كامل بالكمبيوتر لأنتي جرافيتي)

إضافة ومهارة أصلية ومخصّصة للاستخدام الشخصي على **Google Antigravity (Windows)** تمنح الوكيل تحكماً كاملاً ومباشراً بجهازك مع **لوحة تحكم عربية عائمة** و**تفاعل صوتي عربي مباشر**.

## المميزات الرئيسية

- **تحكم كامل بصلاحيات مفتوحة (استخدام شخصي)**: رؤية الشاشة، تحريك ونقر وسحب الفأرة، الكتابة بالعربية والإنجليزية تلقائياً، فتح الإيميل والتطبيقات والمواقع، قراءة شجرة عناصر ويندوز (UIA)، وتنفيذ أوامر PowerShell وخطط متعددة الخطوات (`plan_run`).
- **لوحة تحكم عربية عائمة (Floating Arabic HUD)**: نافذة عائمة أنيقة تبقى فوق النوافذ لتتابع منها ما يفعله الوكيل لحظة بلحظة، مع أزرار **إيقاف فوري**، **إيقاف مؤقت / استئناف**، وخانة توجيه مباشر بالصوت أو الكتابة.
- **تفاعل صوتي عربي مباشر (`voice_speak` و `voice_ask`)**: بدلاً من الاكتفاء بالرد في الشات، ينطق الوكيل بالعربية الطبيعية (بصوت سعودي `ar-SA-HamedNeural` أو `ar-SA-ZariyahNeural` مجاناً عبر Edge Neural TTS، مع دعم اختياري لـ ElevenLabs وبديل أوفلاين Windows SAPI)، ويسألك بالصوت عند الوصول لأي خطوة مهمة (*"وصلت لصفحة الإيميل، وش تبي أسوي؟"*) ويستمع لردك الصوتي بالعربية.
- **مفتاح إيقاف فوري شامل للنظام**: اضغط زر **إيقاف فوري** في اللوحة العائمة، أو اختصار **`Ctrl + Shift + X`**، أو اضغط **`Esc` مرتين بسرعة** من أي تطبيق لإيقاف التحكم وتحرير جميع الأزرار فوراً.

## طريقة التثبيت في Google Antigravity

### الطريقة الأسرع (اطلب من أنتي جرافيتي نفسه يركّبها)
انسخ هذه الجملة وأرسلها مباشرة داخل شات **Google Antigravity**:

```text
استنسخ مستودعي الخاص https://github.com/LOAY109/nida-computer-use.git ثم شغّل سكربت التثبيت install.ps1 لتركيب الإضافة والمهارة عندك، وأكد لي بعد ما يخلص التثبيت.
```

### أو يدوياً عبر PowerShell
```powershell
git clone https://github.com/LOAY109/nida-computer-use.git
cd nida-computer-use
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

## أمثلة للاستخدام بعد التثبيت

بعد إعادة تشغيل Google Antigravity، اكتب `/nida-computer-use` متبوعاً بطلبك:

```text
/nida-computer-use افتح بريدي الإلكتروني واقرأ آخر رسالة مهمة واسألني بالصوت وش أرد عليها
```

```text
/nida-computer-use شغل لوحة نداء العائمة، وافتح مجلد التنزيلات ورتب الملفات
```

## تخصيص الصوت (اختياري)

- افتراضياً تعمل الإضافة بصوت سعودي طبيعي مجاني بدون أي مفتاح API (`ar-SA-HamedNeural`).
- يمكنك تغيير الصوت وسرعة النطق مباشرة من زر الإعدادات داخل اللوحة العربية العائمة.
- إذا رغبت باستخدام **ElevenLabs** بدلاً من Edge TTS، أضف المتغير `ELEVENLABS_API_KEY` (واختيارياً `NIDA_ELEVENLABS_VOICE_ID`) داخل `mcp_config.json`.
